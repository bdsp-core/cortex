# Nature Medicine — figure / display-item specifications

**Publisher:** Springer Nature / Nature Portfolio · **Site:** nature.com/nm · **Researched:** 2026-06-03
**Status:** possible target. **Most detailed + strictest public spec → use as the design ceiling.**

> **Access note:** `nature.com/nm/*` submission pages redirect to login; the authoritative public source is
> Nature Portfolio's **`research-figure-guide.nature.com`** (fully fetched). Specs below are high-confidence
> unless flagged.

## File formats
- **Main figures — preferred VECTOR:** `.pdf` or `.eps` (editable; all text/scale-bars/boxes as vector).
  `.ai` also accepted. Also acceptable: layered `.psd`, `.ppt`→pdf, `.svg`, `.ps`, Excel.
- **Main figures — NOT accepted:** **`.jpeg`, `.tiff`, `.png`** (rasterized main figures rejected), plus
  Canvas/DeltaGraph/TeX/ChemDraw/SigmaPlot/CorelDraw.
- **Extended Data figures:** `.jpeg` (preferred), `.tiff`, or `.eps` only; ≤300 dpi; RGB; ≤10 MB.
- Rule: "Do not rasterize line art or text; supply editable, unflattened vector artwork."

## Resolution
- Photographic images: **≥300 dpi** (min); **450 dpi recommended** for export (online proof max).
- Prefer **vector** for all data figures (no DPI applies). Older tiered guide (line 600–1200 / combo 600)
  is superseded by "prefer vector; 300 dpi photos."

## Dimensions
- **Single column = 89 mm (≈3.5″); double column = 183 mm (≈7.2″).** (88/180 in some older sources; 89/183
  is authoritative current.)
- **Max figure height = 170 mm (≈6.7″).** Extended Data max page = 180 × 170 mm.
- 1.5-column / intermediate: **not specified**.

## Fonts
- **Helvetica or Arial** (sans-serif); Courier for sequences; Symbol for Greek/glyphs.
- Body/label text **5–7 pt** (min 5, **max 7**). **Panel labels: 8 pt, bold, upright, lowercase a, b, c.**
- **Embed fonts (TrueType 2 or 42); do not outline.** Avoid coloured text (use keys/keylines).
- Axis labels include units in parentheses, e.g. `Data (unit)`. Scale bars on a separate editable layer.

## Colour
- **RGB recommended** (wider gamut than CMYK); CMYK accepted but auto-converted. Extended Data: RGB only.
- **No colour charges** for Nature-titled journals (online always free).
- **Colour-blind accessibility REQUIRED:** accessible palette; avoid red/green; text contrast >4.5:1;
  use keys/keylines not colour-only coding.

## Display items (Articles)
- Up to **~8 figures and/or tables** main text (secondary sources; login-gated page — verify at submission)
  **+ up to 10 Extended Data** items (each ≤1 page 180×170 mm, JPEG/TIFF/EPS, ≤10 MB, author-styled, cited
  in main text).

## Line weight / file size
- **Lines/strokes 0.25–1 pt** (stated for Extended Data; apply to main figs too). Main figure file ≤ **50 MB**.

## Legends / integrity / AI
- Legends below figures; must give brief title, per-panel description, **n, error-bar definition, test,
  significance thresholds**, scale bars. Word limit not specified.
- **Generative AI in figures PROHIBITED** (incl. Photoshop content-aware/Generative Fill, healing/clone,
  erasers). Non-generative ML image tools must be disclosed in the caption. Brightness/contrast only if
  uniform across the whole image + controls. Life-science papers screened with **Proofig**.

## Gaps / not specified
DPI tiers by type (consolidated to "vector + 300 dpi photos"); legend word limit; 1.5-col width; per-figure
colour fee named for Nature Medicine specifically; supplementary-figure cap (beyond the 10 Extended Data).
