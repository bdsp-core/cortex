## File formats
- Elsevier recommends **only EPS, PDF, TIFF, or JPEG** (+ MS Office files accepted).
  - Vector / line art / charts → **EPS (preferred) or PDF**.
  - Halftone photos/micrographs → **TIFF (recommended) or JPEG (max quality)**.
  - Pure B/W line art → TIFF (bitmap mode). Combination (halftone+line) → TIFF/JPEG max quality, or EPS.
- **PNG: not yet officially accepted** ("submission systems in progress of updating").
- Journal guide confirms: "TIFF (or JPEG), EPS (or PDF), or MS Office files."

## Resolution (at final publication size)
- **Line art (B/W, no tints): 1000 dpi** (**1200 dpi** if very fine line weights).
- **Grayscale & colour halftone: 300 dpi.**
- **Combination (halftone + line): 500 dpi.**
- EPS combination: 300–500 dpi halftone component + 1000 dpi line component. Pure vector = scalable (n/a).

## Dimensions (Elsevier sizing)
| Class | Width | inches |
|---|---|---|
| Minimal | 30 mm (85 pt) | 1.18″ |
| **Single column** | **90 mm** (255 pt) | **3.54″** |
| **1.5 column** | **140 mm** (397 pt) | **5.51″** |
| **Double column** | **190 mm** (539 pt) | **7.48″** |
- Max height: **not stated**. Aim for uniform look across all figures in an article.

## Fonts
- Preferred (embed): **Arial (or Helvetica), Courier, Symbol, Times (or Times New Roman)** — Type 1 or
  TrueType only; non-standard fonts may be substituted → missing symbols.
- **Minimum size in finished art: 7 pt** normal text; **≥6 pt** sub/superscripts. Don't vary lettering size much.

## Colour
- **Submit RGB** (Elsevier converts to CMYK for print; do not submit CMYK).
- **Online colour: free.** **Print colour: charged** (corresponding author notified post-acceptance).
- **Journal carve-out:** colour figures for **functional neuroimaging (MRI, PET, SPECT)** may be **printed
  free at the Editor's discretion.**
- **CVD guidance (Elsevier):** use CVD-safe palette; high contrast; replace red with magenta in red/green
  fluorescence; simulate via Photoshop "Proof setup"; consider non-colour encodings (shape/position/line type).

## Display items by article type (from search snippets)
| Type | Words | Figs/Tables | Refs |
|---|---|---|---|
| Letters to the Editor | <1000 | **1 figure or 1 table** | ≤5 |
| Opinion/Editorial | ≤3 pp (no abstract/keywords) | 1 figure or 1 table | ≤20 |
| **Original Article** | not stated | **figure cap not specified (gap)** | not stated |
| Review | by invitation | not specified | — |
- Abstract ≤200 words; title ≤135 chars (abbrevs allowed: EEG, EMG, MEG, MRI, tDCS, TMS).

## Line weight / file size
- **Line width: 0.25 pt recommended, 0.1 pt absolute minimum**; prominent plot lines ≈1 pt; EPS range 0.10–1.5 pt.
- **File size: ≤10 MB per figure; ≤7 MB each if many figures.**

## Legends / permissions / integrity / AI
- **Captions supplied separately** (not on the figure) — dedicated caption item or listed at end of the
  manuscript text. Each illustration has a caption: brief title + description + all symbols/abbreviations.
- Reproduced material → written permission + acknowledgement.
- Integrity: no feature enhanced/obscured/moved/removed/introduced; brightness/contrast/colour-balance only
  if they don't obscure original info.
- **AI images:** must **not** create/alter primary data images (microscopy, histology, blots, radiology,
  patient images) or graphical abstracts. **Allowed:** explanatory/conceptual diagrams (flow charts,
  schematics) and data-derived visualizations via reproducible methods — **with disclosure** in the caption
  + a declaration before references.
- Cover figures encouraged (aesthetically interesting, preferably colour).

## Gaps / not specified
Max figure height; **Original-Article figure/table cap + word limit**; Review limits; multi-panel labeling
convention (not mandated by Elsevier or the journal); caption word limit; exact print-colour fee.
