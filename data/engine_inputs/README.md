# Engine inputs (self-contained, in-repo)

The data the engine actually reads, in one place, in this repo,
resolved in code through `engine_paths.py`. Provenance, sha256, the
D3 shared-lineage proof and self-checks: `MANIFEST.json`.

## Producer (Phase 5 reconciliation — read this)

The authoritative artifact `sdt_fits.csv` is produced by
**`pipeline/run_unified_calibration.py` STEP d** — the
reference-faithful CV-Youden recompute on the **unified `data/labels/`
corpus** (Phase 3): 14,214 rows, the 6 IIIC domains
`{sz,lpd,gpd,lrda,grda,iic}` stacked with a `domain` column. It is
exercised + **gated green** by `tests/test_phase3_calibration.py`
(Q2-lock / R5-name join) and the Mode-A / Mode-B suites.

`scripts/build_engine_inputs.py` does **not** build this directory.
PRE-Phase-5 it vendored the *sibling* repo
(`../ilae-skill-certification-test-main/data/prepared/`, the 219-row
15/29-rater era). That path is **RETIRED** — re-running it would
*regress* engine_inputs to the legacy artifact and re-introduce the
sibling dependency (a D9/D3 violation). The script is now a
**self-verifying MANIFEST verifier/regenerator** for the *current*
in-repo artifact (no sibling reads): it records the true producer,
the D3 `data/labels` sha256 lineage anchor, live `output_sha256`, and
self-checks the gated correctness contract.

## D3 — shared lineage with deployment_prior

`MANIFEST.json` records `data_labels_provenance` = sha256 of
`data/labels/{labels,raters}.csv` and **cross-checks it equals** the
anchor in `data/deployment_prior/summary.json`
(`data_labels_provenance`). Equal ⇒ `engine_inputs/` and
`deployment_prior/` are **provably derived from the same unified
corpus** (plan D3). The verifier fails loudly if they diverge.

## Not here (by design)

- **`Sigma_l_fitted.npy`** — stays at repo root. FROZEN 15-rater-era
  artifact (its `Corr_l` differs from the current 29-rater matrix;
  regenerating would silently change the hierarchical prior). Immutable
  vendored input; recorded in MANIFEST; resolved via
  `engine_paths.SIGMA_L`.
- **`cert_config.yaml`** — repo root, hand-maintained config (not
  derived data); resolved via `engine_paths.CERT_CONFIG`. The
  reference-faithful v13 is `calibration/cert_config.yaml`
  (`engine_paths.CALIB_CERT_CONFIG`).
- The original plan's `data/consolidated/` — **does not exist**
  (retired in Phase 1, zero consumers); dropped from the Phase-5 gate.

unless: `sdt_fits.csv` has the 6 IIIC domains; the 29 Q2-locked
candidates + the 4 R5 name-variants
(`Aaron F. Struck`,`Hiba A. Haider`,`Jonathan J. Halford`,

engine_inputs *content* itself, re-run the Phase-3 pipeline
(`pipeline/run_unified_calibration.py`), not this script.
