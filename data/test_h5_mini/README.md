# test_h5_mini — sample test cases (1 per class)

7 H5 files (~9 MB total) — one example per IIIC pattern class plus one
spike-positive example. Generated by sampling from the canonical 200-case
test set at `s3://bdsp-opendata-credentialed/eeg-test/test_h5.h5`.

| filename | class | source_dataset |
|---|---|---|
| `test_iiic_seizure_*.h5` | IIIC seizure plurality | sparcnet50K (10-min context) |
| `test_iiic_lpd_*.h5`     | IIIC LPD plurality     | sparcnet50K |
| `test_iiic_gpd_*.h5`     | IIIC GPD plurality     | sparcnet50K |
| `test_iiic_lrda_*.h5`    | IIIC LRDA plurality    | sparcnet50K |
| `test_iiic_grda_*.h5`    | IIIC GRDA plurality    | sparcnet50K |
| `test_iiic_other_*.h5`   | IIIC Other plurality   | sparcnet50K |
| `test_spike_*.h5`        | spike-positive         | morgoth1:spikes |

## Per-case schema

IIIC cases:

```
/eeg30s          (20, 6000) float32   30-sec central EEG @ 200 Hz
    attrs: fs_hz, channel_names (S16 array of 20 names ending in EKG)
/sdata           (n_times, n_freqs*4) float32   10-min multitaper
                                                spectrogram, regions
                                                LL/RL/LP/RP stacked
/sfreqs          (n_freqs,) float32
/stimes          (n_times,) float32
root attrs:
    seg_id (int), test_class='iiic', pattern_class (str),
    n_raters (int), source_dataset (str), patient_id (str),
    spec_source (str), source_window_center_s (float),
    sdata_duration_s (float)
```

Spike cases:

```
/eeg30s          (20, 3840) float32   30-sec central EEG @ 128 Hz
    attrs: fs_hz, channel_names (S16 array)
root attrs:
    seg_id (int), test_class='spike', spike_category='1',
    n_raters (int), source_dataset='morgoth1:spikes', patient_id (str)
```

## Full test set

The full 100 IIIC + 100 spike test set (175 MB) is at
`s3://bdsp-opendata-credentialed/eeg-test/test_h5.h5`. Bundle layout:

```
/iiic/<seg_id>/   {eeg30s, sdata, sfreqs, stimes}  + per-case attrs
/spike/<seg_id>/  {eeg30s}                          + per-case attrs
```

Index at `s3://bdsp-opendata-credentialed/eeg-test/manifest.csv`.

The original one-off extraction script is not part of the shareable
repository. Treat these files as frozen test fixtures; reconstructing them
requires authorized access to the governed full test set and a new,
provenance-recorded extraction rather than an undocumented local script.
